# FX — Autonomous Agent Systems 🧠

An interactive explainer for how an autonomous agent team works: an Orchestrator breaks a goal into jobs, picks the right agents, and brings their answers together.

**▶ Live demo:** https://arecibo-sys.github.io/fx-autonomous-pres/

## Features
- Click a **role** (Researcher, Engineer, Security Reviewer) to see what it does
- Step through the **5-stage execution loop** (Standby → Activate → Work → Report → Standby)
- Keyboard navigation with **←** and **→** arrows
- Subtle **WebAudio beeps** (sound off by default, toggle the button)
- Smooth crossfades and staggered entrance animations
- Reduced-motion support and visible keyboard focus rings

## Tech
- Single-file HTML + CSS + vanilla JS, zero dependencies
- Fully offline and self-contained

## Design
- Sci-fi dark theme: neon mint on near-black with amber accents
- Monospace type, tight display headings
